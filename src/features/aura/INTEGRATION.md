# Book aura

Copy this folder into the Capacitor app. It depends only on `react`, `three`, `@react-three/fiber`, `@react-three/drei` and `zustand`. Shader sources are imported with Vite's `?raw` (`glsl.d.ts` in this folder). Nothing here imports the playground's book mesh, shelf, lights, catalog or routes.

The shader blooms around **one** focused book. A second mesh exists only during the ~500ms crossfade, and it is hidden the rest of the time. Both meshes share one compiled program.

## Signals

`BookAuraSignals` in `types.ts` is the contract. Example values live in `mockData.ts` and are labelled example data. There is no real taste, rating, read-state, ownership or friends source yet.

| Field | Range | What it does |
| --- | --- | --- |
| `alignment` | 0..1 | Vibrance and how many of the four colours appear. Low is dim and nearly one colour. |
| `liked` | -1..1 | Spread and sparks. Below zero pulls the bands tight and grey. |
| `read` | 0, 1, 2, 3 | Unread (slow drift), reading (flow plus a progress arc), finished (settled rings), 3 = read state not shared. |
| `progress` | 0..1 | Arc along the cover while `read` is 1. |
| `owned` | 0..1 | 1 anchors a rim to the cover. 0 is detached mist. |
| `invite` | 0..1 | Soft pool in `friendColor` when a friend can lend it and the viewer does not own it. |
| `embers` | up to 3 | Dots under the book. `lit` 1 is available, 0 is hollow (lent out or not lending). |
| `extra` | 0..n | Friends past the three dots, drawn as `+N`. |
| `quiet` | boolean | A small neutral dot on an unfocused book that someone can lend. |

Styles are `aurora`, `chakra` and `arcane` (`styles.ts`). Colours are `Vector3` sRGB 0..1, not `THREE.Color`.

Plain-words copy for the focused book comes from `labelFor` (`Very you · Loved · Finished · Yours`, `Freja can lend this`).

## Using it on a shelf

Inside the same `<Canvas>` as the books:

```tsx
const itemsRef = useRef(items);
itemsRef.current = items;

<group
  ref={group}
  onClick={() => {
    const { focusedId, focusIndex, clear } = useAuraFocus.getState();
    if (focusedId === book.bookId) clear();
    else focusIndex(index);
  }}
>
  <Book />
</group>
<FocusedAura itemsRef={itemsRef} />
```

Register the group once it exists. `dimensions` are the box size in the group's local space (the `BoxGeometry` args), before the parent scale:

```tsx
useLayoutEffect(() => {
  const group = groupRef.current;
  if (!group) return;
  useAuraFocus.getState().register(book.bookId, {
    object: group,
    dimensions: book.dimensions,
  });
  return () => useAuraFocus.getState().register(book.bookId, null);
}, [book.bookId, book.dimensions]);
```

`FocusedAura` projects the eight corners of that box into CSS pixels and billboards a plane at the book's distance from the camera. The plane is `cover + 2 * 1.45 * min(coverWidth, coverHeight)`.

Material, on purpose: `transparent: false` (opaque list), `depthTest` and `depthWrite` false, `AdditiveBlending`, `renderOrder: -1`, `toneMapped: true`. It draws before the book, so the additive colour does not tint the cover. Raycasting is disabled on the aura, the embers and the quiet dots. `uInnerGlow` stays 1; the book covers the haze inside the cover. Set it to 0 only for a transparent motif.

Clicking the focused book again clears it. Clicking empty space should clear it too: put a catcher mesh behind the books (`colorWrite: false`, `depthWrite: false`) and call `clear()`. Only one id is focused. The previous aura's bloom moves to 0 over 0.5s while the next moves to 1, so two meshes are visible only during that handoff. The incoming aura waits until the carousel is within 0.75 of the new book and the pointer is not dragging.

`prefers-reduced-motion: reduce` (see below) swaps instantly and freezes the pattern.

## This playground

Open `/aura` (with this app's base path, `/threejs/aura`).

| Query | Effect |
| --- | --- |
| `shelf=freja` | Example friend shelf. Default is your shelf. |
| `share=owned` or `reading` | What Freja shares. Default `likes`. |
| `style=chakra` or `arcane` | Default `aurora`. |
| `focus=2` or a book id, or `none` | Starting book. A small index stays a number in the URL. |
| `rm=1` | Force reduced motion. |
| `dev=1` | Open the example-signal sliders. Nothing is saved. |
| `t=3` | Freeze shader time, in seconds. |

`?aura=1` on the library URL is **not** wired. That would mean editing `src/routes/index.tsx`.

## Capacitor

### WebView WebGL performance

- Keep a single `<FocusedAura>`. Do not mount a shader per book. At rest one mesh is visible; the second is `visible: false` until a crossfade.
- The plane has `depthTest: false`, so it shades every fragment of that quad every frame. It is only as large as the cover plus the margin, not the screen.
- Cap `devicePixelRatio` on the canvas. This playground already does, via `currentRenderQuality()`: `[1, 1.5]` normally and `[1, 1]` on low-end phones. Do not pass an uncapped `window.devicePixelRatio` (often 3 on phones). A 3× canvas is about 4× the fill of 1.5×.
- A single frame advances the crossfade and the shader clock by at most 100ms, so a long WebView hitch does not skip the fade. Frames at 30fps still move in real time.
- Reuse the screen's existing lights. This demo adds `Lightning` only because the route's canvas would otherwise be black. A second `Environment` on a screen that already has one doubles the PMREM cost.
- When the app backgrounds (`App.addListener("appStateChange")`), set `auraMotion.reduced = true` or `auraMotion.frozenTime` so the WebView stops animating the shader.
- `powerPreference: "high-performance"` is set on this demo canvas only. WKWebView often ignores it. Prefer the host canvas settings.

### Touch and tap

- The carousel uses pointer events. A move of 6px or less is a tap. A larger move drags the row and the following click is ignored, so a swipe does not also toggle focus.
- Put `touch-action: none` on the book stage (`touch-none` in this demo) so the WebView does not turn the gesture into a scroll or a pinch-zoom. If the aura sits inside a scrolling page, set that only on the stage.
- Tap the focused book again, or tap empty space, to clear focus. Prev/next buttons are `display` none below 700px; swipe still works.
- iOS can still scroll the document if a parent is scrollable. If that happens, listen for `touchmove` on the canvas with `{ passive: false }` and `preventDefault()` while the gesture starts on the stage. Do not do that on the whole page.
- Do not use `dblclick`. Older WebViews delayed it by 300ms. `click` after `pointerup` is enough on current WKWebView and Android WebView.

### devicePixelRatio

- Ember and quiet-dot size is `gl_PointSize = aSize * uPR`, and `uPR` is `gl.getPixelRatio()`. Capping the canvas dpr keeps the dots the same CSS size and cuts fragment work.
- The `+N` tag is a small canvas texture, not a high-resolution target.
- Recommended cap: `dpr={[1, 1.5]}`, or `dpr={[1, 1]}` when the device is low-end or the user has asked for a lighter mode.

### Reduced motion

- `usePrefersReducedMotion` subscribes to `(prefers-reduced-motion: reduce)`. iOS Reduce Motion and Android's remover-animations setting surface through that query in the WebView.
- When it matches, or when the host sets `auraMotion.reduced = true`: the carousel jumps instead of gliding, the aura swaps in one frame (still one visible mesh), `uMotion` is 0, and `uTime` stays at 3 so the pattern is readable and still. The label does not crossfade.
- The demo also accepts `?rm=1`. An in-app switch should set the same flag, not a second code path.
